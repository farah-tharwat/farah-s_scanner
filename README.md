This project acts a scanner mainly for rectangular documents.it consists of 3 files ,the 1st one is the Bird_eye_view.py ; this one just gets the document in the proper position if it was slanted,or taken in any degree except for 90 degrees.
the 2nd one is the Transformation.py ;it does the actual scanning of the image but it works manually by entering the coordinates of the image but that's sophisticated since each image has its own resolution and a lot of other details.
the last one is Auto_transformation.py ;it does the actual scanning of the image but it works automatically.
